BANNEDPRODUCT MEDIA INC. — Logo Files
======================================

Drop your logo image files here with the following names:

  logo-nav.png
    Used in the site header (navbar). Recommended: horizontal/text logo on
    transparent or dark background. Ideal height: ~90–120px so it renders
    sharp at 46px display height. Use the "Primary Logo (Clean)" or the
    flaming mic with text.

  logo-footer.png
    Used in the site footer. Same as nav logo or larger version.
    Ideal height: ~120–180px (renders at 60px display height).

  logo-primary.png
    Full primary logo (distressed rectangular version). Used on brand/about pages.

  logo-microphone-black.png
    Flaming microphone logo on white/transparent background.

  logo-microphone-dark.png
    Flaming microphone logo on black background.

  logo-icon.png
    The "BP" icon version. Used for favicon, thumbnails, etc.

  brand-kit.png
    Full brand kit overview sheet.

NOTES:
- PNG format preferred (supports transparency)
- Use original high-resolution files
- The site will automatically display logo-nav.png in the header
  and fall back to a styled text logo if the file is missing.
